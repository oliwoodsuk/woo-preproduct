*** PreProduct – Smarter Pre-order and Deposit Changelog ***

2026.05.22 - version 1.0.0
* Initial release of PreProduct – Smarter Pre-order and Deposit for WooCommerce
* Pre-orders with charge-now, charge-later, and deposit modes
* Seamless WooCommerce integration with environment-aware endpoint detection
* Automatic add-to-cart button tagging for simple products
* Admin dashboard integration via iframe
* Script injection with defer attribute for optimal performance
* Webhook notifications for plugin lifecycle events (activation, deactivation, uninstall)
* Security features including HMAC-SHA256 signature verification
* Comprehensive error logging using WooCommerce logger
* Plugin action links for easy access to settings and documentation
* WordPress and WooCommerce coding standards compliance
